\## 📌 About



NexusGate is an AI API Gateway that provides a single interface for applications to interact with AI models.



Instead of connecting an application directly to an AI provider, NexusGate handles authentication, API key validation, rate limiting, request tracking and AI model routing through one centralized gateway.



\## ✨ Features



\- User authentication

\- API key authentication

\- Gemini AI integration

\- Intelligent model routing

\- Rate limiting

\- Request tracking

\- Usage analytics

\- PostgreSQL database

\- Prisma ORM

\- REST API

\- React dashboard

\- AI Playground

\- Production deployment
